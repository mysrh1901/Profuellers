Custom LLM

🧠 KAVACH Compliance LLM — Our Own Model

Fine-Tuning Pipeline — How We Built It

Step 1: Collect training pairs
Each example = "here's code" → "here's the compliance violation"
Source: past audit findings, Checkmarx reports, SOX evidence, MSA clauses
Volume: 500-1000 pairs (started with 15, expanding)

Step 2: Freeze model, train small adapters (QLoRA)
Base model: Llama 3.2 (1.2B params) — frozen at 99.7%
We add 4M trainable adapter parameters on top
Train only adapters on our data (~2-6 hours, one GPU, ~$50-100)

Step 3: Merge, export, deploy
Merge adapters back into base → export to Ollama format
Result: kavach-compliance-v1 — runs on our infra
No client code sent to external APIs (stays within our network)

Knowledge Graph + GraphRAG

🕸️ Compliance Knowledge Graph with Graph RAG

How GraphRAG Works in KAVACH

1. Compliance Knowledge Graph — All regulations, controls, and systems modeled as connected nodes with relationship edges (violates, requires, triggers, penalizes).

2. Causal Path Traversal — On event, traverse the graph to find all downstream impacts. E.g.: SQL injection → PCI-DSS 6.5 → MSA §7.2 SLA → $50K penalty → SOX disclosure.

3. RAG (Retrieval-Augmented Generation) — Retrieved paths are passed as context to our LLM, enabling precise regulation-aware reasoning instead of generic responses.

4. Output — Structured multi-domain impact with regulation references, severity, and actions — within 2 seconds.
JGraphT Engine Causal Path Analysis LLM Context Enrichment

Example: How One Finding Cascades

A developer introduces SQL injection in the loan search module. Here's how KAVACH traces the full compliance impact through the graph:
SQL Injection Found
├── violates PCI-DSS 6.5 (secure coding requirement)
├── violates OWASP A03 (injection prevention)
├── triggers MSA §7.2 SLA (48-hour clock starts)
│ └── penalty: $50,000/incident
├── requires Code Review (before any fix can ship)
│ └── satisfies ITGC-CM-06 (SOX change control)
└── blocks Deployment (gate status: BLOCKED)
What the AI receives: These traced paths + the actual code + the client's specific contract terms. It then generates a complete compliance assessment referencing specific regulation sections — not generic advice.
