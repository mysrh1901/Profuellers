Architecture — 90 seconds

Architecture Walkthrough

"The architecture has 5 layers:

Event Sources — Git hooks, Jenkins CI/CD, Jira, AWS Config, File Watcher. Any system change can trigger analysis. How? Each tool sends a webhook (HTTP POST) to our API when something happens. Git sends a webhook after every commit. Jenkins sends one after every build. Jira sends one when a ticket moves. Our API receives it, creates an event, and puts it in the queue. It is a standard integration — every modern tool supports webhooks out of the box.

Message Queue — ActiveMQ. Decouples ingestion from processing. Handles high volume.

6 Agents — Each autonomous. Digital Twin maintains client score. Chain Reactor traces cross-domain impact. Audit Narrator writes evidence. Drift Sentinel catches slow degradation. Obligation Parser reads contracts. Control Ingestion adds new frameworks.

Intelligence Layer — Our own fine-tuned LLM, Knowledge Graph for causal reasoning, Policy Engine with 26+ rules.

Outputs — Deployment gate (block/allow), auto-generated audit evidence, real-time dashboard, alerts."

Our Own LLM — 2 minutes

How We Built Our Own Model

"A common question — are we just calling ChatGPT? No.

We took Llama 3.2, which is an open-source model by Meta — free to download. We installed it on our server. Then we trained it on our compliance data — hundreds of examples showing 'when you see this code, the compliance issue is this.'

How training works: It is like training a new team member. You show them 500 examples — 'see this SQL concatenation? this violates PCI-DSS 6.5. See this hardcoded password? this violates SOX ITGC-AC-01.' After enough examples, they can look at new code and say 'this pattern violates this regulation.' Same concept — just automated.

How the code understands: Inside the model there are 1.2 billion numbers (called weights). During training, these numbers adjust slightly each time the model gets an answer wrong. After 500 examples repeated 3 times, the numbers settle into a pattern where: seeing SQL concatenation → activates the same internal pathway that produces 'PCI-DSS 6.5 violation.' It is pattern recognition at massive scale — the model does not 'understand' like a human, but it recognizes patterns reliably because it has seen hundreds of similar examples during training.

What we trained on: Past SAST findings mapped to regulations, SOX audit evidence, MSA contract clauses. All from real Hexaware engagement experience. Each training example is stored in a file (compliance_training.jsonl) — you can open it and see exactly what the model learned from.

After training, the model sits on our server permanently. When a developer commits code, that code goes to our machine for analysis. It never leaves our network. Not to Meta, not to OpenAI, not to anyone.

Cost: GPT API at 5000 events per day = $6000 per month. Our server = $1000 per month, unlimited calls. At scale, we save 80%."
"But you are sending data to Llama?" → "No. Llama is installed on our server like any software. It is not a cloud service. Think of it like installing Microsoft Word — Microsoft does not see your documents."
Knowledge Graph — 90 seconds

Graph RAG — How Regulations Connect

"The second AI component is our Knowledge Graph.

Regulations do not exist in isolation. A SQL injection violates PCI-DSS. PCI-DSS violation triggers the client's MSA SLA. MSA says fix in 48 hours or pay $50K. Fixing requires code review per SOX ITGC. These are connected.

We model all these connections as a graph. When a finding occurs, we trace the connections to discover all downstream impacts. Then we pass those connections to our LLM so it can reason with full context — not guess from general knowledge.

Example: SQL injection found in loan module. Our graph traces: violates PCI-DSS 6.5 → triggers MSA Section 7.2 (48h, $50K) → requires code review (ITGC-CM-06) → blocks deployment. All in 2 seconds."
"What is RAG?" → "RAG means Retrieval-Augmented Generation. Instead of the AI guessing, we first retrieve relevant regulation connections from our graph, then give those to the AI as context. The AI reasons with specific facts, not general knowledge."
